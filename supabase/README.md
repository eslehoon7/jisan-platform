# Supabase 서버 함수 (Edge Functions) 사본

실제 실행은 Supabase 프로젝트(jisan-platform)에서 돼요. 이 폴더는 보관·기록용 사본이에요.
비밀 키(NTS_SERVICE_KEY 등)는 코드에 없고 Supabase 대시보드 → Edge Functions → Secrets 에만 있어요.

- molit-sync: 국토부 실거래가 자동 수집 (매일 새벽 3:10)
- bld-info: 건축물대장 조회 (건물명·준공·층수·주차)
- nts-check / business-apply: 국세청 사업자 확인 / 사업자 가입 신청
